# SAÉ 2.2 — Othello GUI

## 📌 Description

This project was developed as part of the SAÉ 2.2 coursework. It focuses on creating a graphical interface for **Othello**, a strategy board game played by two players using black and white discs on an 8×8 board.

## 🎯 Objectives

- Design a simple and intuitive graphical interface.
- Display the game board and discs.
- Allow players to interact with the interface.
